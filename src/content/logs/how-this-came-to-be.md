# The Idea

Hi there! Anant this side, and I’m going to talk about how this website came to be. I’ll keep it short because stretching something unnecessarily gets boring, tedious, and really hits a nerve.

I was reading a book called [_Strange Pictures_](https://www.goodreads.com/book/show/216670080-strange-pictures) by Uketsu with a friend, and in the book, there’s this guy who writes short and casual blogs. The whole novel is fantastic, I really liked the writing style of the author and how the story unfolds; but what stuck with me was this idea of writing short and casual blogs. Since then, I’ve been thinking about doing something similar.

# The Process

This idea lingered for a while, and I was considering building a site for it. Of course, I wasn’t sure about the aesthetics of the blog website until recently, when I read an article about [feature creep](https://vanschneider.com/blog/edition-268/), on how adding too many features can ruin a product. That’s when it clicked, "I should make a very simple, and minimal website." So minimal that there’s nothing on it but a link to the next page or the content itself.

# The Result

Hence, I built this website 🎉 directory-style and minimal, "inspired" by Adarsh's [portfolio](https://www.adarshdubey.com/).

> “Good artists copy, great artists steal.” — Pablo Picasso

Where the user doesn’t have to think much. They can explore the whole thing in few minutes and if they like the content, they can go and read it; if they don’t find it useful, then they can spend their time on something more worthwhile. I know this because I am that user.

As I’ve been working on this website for the past few days, I’ve added a few components here and there so that at least it looks like some work has been done on it. I’m proud of what I’ve built so far, and while the aesthetics might change in the future, who knows, I might just focus on writing now, which was the original goal.

# The End

For those who don’t know me, I’m not sure how you found this site since it’s only known to a few of my friends (although I'm planning to announce it on X or something) but if you’re here, I’m [Anant Dubey](https://www.anantdubey.com/), I work in tech, and some of my hobbies include music, media, games and such; though I'm not getting as much time these days to follow through.

Okay then, true to my promise, I’ll keep this blog short and casual. This was the first edition of my blog series.
